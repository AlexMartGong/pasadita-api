# AGENTS.md

Compact repo-specific guidance for OpenCode sessions.

## Build & Run

- **Build tool**: Maven Wrapper only (`./mvnw`). Do not use system `mvn`.
- **Common commands**:
  - `./mvnw clean compile`
  - `./mvnw test`
  - `./mvnw test -Dtest=PasaditaApiApplicationTests`
  - `./mvnw clean package`
  - `./mvnw clean package -DskipTests`
  - `./mvnw spring-boot:run`
  - `./mvnw spring-boot:run -Dspring-boot.run.profiles=prod`
- **REST Docs**: Generated by the Asciidoctor Maven plugin during `prepare-package`. Run `./mvnw clean package` to produce HTML docs.

## Architecture

- **Entrypoint**: `com.pasadita.api.PasaditaApiApplication`
- **Layered packages**: `controllers`, `services` (subpackages by domain), `repositories`, `entities`, `dto` (subpackages by domain), `enums`, `mappers`, `exceptions`, `utils`, `validation`, `security`, `config`.
- **Service pattern**: Interface + `Impl`. Example: `EmployeeService` + `EmployeeServiceImpl`.
- **Dependency injection**: Newer code uses Lombok `@RequiredArgsConstructor` with constructor injection. Some older services still use `@Autowired` field injection; prefer constructor injection for new code.
- **ConfigurationProperties scan base**: `com.pasadita.api.config`. Any new `@ConfigurationProperties` class must live under that package or it will not be picked up.

## Database & Schema

- **DB**: MySQL, database name `la_pasadita_database`.
- **Default local credentials**: `root` / `Root1234` (see `application.properties`).
- **Schema source of truth**: `src/main/resources/scriptLP.sql`. Production uses `spring.jpa.hibernate.ddl-auto=validate`. Keep entity column names, nullability, lengths, and indexes aligned with this script or production startup will fail.
- **Timezone strategy**: DB stores all dates in UTC. Use `DateTimeUtils` for conversions; do not manually juggle timezones.
  - `DateTimeUtils.nowUtc()` — save to DB
  - `DateTimeUtils.nowMexico()` — default date ranges
  - `DateTimeUtils.toMexicoTime(datetime)` — API responses
  - `DateTimeUtils.toUtc(datetime)` — user input

## Security

- JWT with custom filters (`JwtAuthenticationFilter`, `JwtValidationFilter`).
- Role annotations on controllers: `@PreAuthorize("hasAnyAuthority('ROLE_ADMIN', ...)")`.
- Roles: `ROLE_ADMIN`, `ROLE_CAJERO`, `ROLE_PEDIDOS`.
- CORS is restricted to `https://lapasadita.app` in production (`application-prod.properties`).

## Invoicing (CFDI) Quirk

- Uses Facturapi SDK 1.2.0 for customer/product creation, but **the invoice POST bypasses the SDK** because its deserializer is incompatible with CFDI 4.0 responses.
- Direct REST call is made via JDK `HttpClient` bean (`facturapiHttpClient`) with `Authorization: Bearer ${facturapi.key}`.
- `FacturapiConfig` exposes both the SDK bean and the shared `HttpClient` bean.

## Object Storage (Cloudflare R2)

- **S3-compatible** storage via AWS SDK v2 (`software.amazon.awssdk:s3`, version managed by the AWS SDK BOM in `pom.xml`).
- Config bound to `R2Properties` (`@ConfigurationProperties(prefix = "cloudflare.r2")`, record under `config/`); all values from env vars (`R2_ACCESS_KEY`, `R2_SECRET_KEY`, `R2_ENDPOINT`, `R2_BUCKET` defaults `lapasadita-assets`, `R2_PUBLIC_URL`). Dev `application.properties` ships dummy fallback defaults for these (and for `CSD_*`/`FACTURAPI_KEY`), so local startup works without real secrets; production requires the real env vars.
- `S3Config` exposes the `S3Client` bean: endpoint override, static R2 creds, `Region.US_EAST_1`, path-style access enabled.
- `StorageService` / `S3StorageServiceImpl` (under `services/storage/`): `uploadFile(MultipartFile, folder)` stores under `folder/<uuid>.<ext>`, returns `publicUrl + "/" + key`. Wraps `IOException`/`SdkException` in `BusinessRuleException` (400).
- **Product images**: `POST /api/products/{id}/image` (`ROLE_ADMIN`/`ROLE_CAJERO`) uploads to the `products` folder and persists `Product.imageUrl` (`image_url varchar(255)`, exposed in `ProductResponseDto`).

## Exception Handling

- Centralized in `GlobalExceptionHandler` (`@RestControllerAdvice`).
- Throw `EntityNotFoundException` (404) or `BusinessRuleException` (400) from services. Never return `null` or set HTTP status inside services.

## Testing

- Current test suite is minimal. `PasaditaApiApplicationTests` only loads the context.
- There is an `InvoiceServiceImplTest`, but most domains lack unit/integration tests.
- Surefire runs with `-XX:+EnableDynamicAgentLoading` (JDK 21 dynamic-agent warning, Mockito/Byte Buddy).

## CI/CD

- **Deploy**: Push to `main` triggers a GitHub Actions workflow that builds `./mvnw clean package -DskipTests`, SCPs the JAR to a DigitalOcean droplet, and restarts a `systemd` service (`pasadita`).
- **Lint**: Qodana JVM Community runs on PRs and `main` pushes.

## WebSocket

- Printer endpoint: `/ws/printer?stationId={stationId}`
- Handler: `PrinterWebSocketHandler`
- Sale ticket print is dispatched async from `SaleController.saveSale` (not the service), gated on
  `SaleCreateDto.printTicket` (transient `Boolean`, defaults true). `false` skips printing; omitted/`null` still prints.
- Drawer command decoupled from printing: `sendOpenDrawerCommand(stationId)` sends `{"type":"OPEN_DRAWER","timestamp":<utc>}`.
  Fires automatically when `printTicket == false` and the sale is cash (`paymentMethodId == 1L`), and manually via
  `POST /api/sales/open-drawer?stationId=` (`ROLE_ADMIN`/`ROLE_CAJERO`; `400` if `stationId` missing/blank).

## Entity Conventions

- `@ManyToOne(fetch = FetchType.LAZY)`
- `@OneToMany(mappedBy = "...", cascade = CascadeType.ALL, fetch = FetchType.LAZY)`
- `@OneToOne` with `unique = true`
- `@EqualsAndHashCode(of = "id")`
- Exclude collections from `@ToString` to avoid lazy loading issues
- Default values use `@Builder.Default`
